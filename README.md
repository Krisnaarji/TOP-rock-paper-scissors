# Rock Paper Scissors (Now with UI!) 🪨📄✂️

This is a simple JavaScript project originally built as part of [The Odin Project's Foundations course](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).  
~~The game runs entirely in the **browser console**~~  

**Now updated with a visual user interface (UI) in the browser!**

---

## 📚 About the Project

The original goal of this project was to practice basic JavaScript skills including:

- Writing functions
- Using control flow (if/else/switch)
- Handling user input via `prompt()`
- Generating random choices
- Tracking state with variables
- Basic project structure (HTML + JS)

---

## 🛠 Features

- ~~Play 5 rounds of Rock Paper Scissors in the console~~  
- Play unlimited rounds in the browser with a user-friendly interface  
- Randomized computer moves
- Score tracking for both the player and computer
- Clear feedback and round results shown on the page
- Responsive and styled layout using CSS
- Toggle UI visibility with "Play Game" / "Go Back" button

---

### ✨ UI Update

This version expands on the original by introducing a full **web-based UI**:

- Styled layout with CSS
- "Play Game" button to toggle gameplay
- Dynamic score display for player and computer
- Interactive buttons for selecting Rock, Paper, or Scissors
- Real-time game updates and results without using the console
- Game result messages after each round
- Dynamic creation and removal of elements with JavaScript

---

## 🧠 Learning Focus: DOM Manipulation

The project explores essential concepts of DOM manipulation in JavaScript, including:

- Selecting and interacting with HTML elements
- Creating, updating, and removing elements dynamically
- Modifying content and attributes
- Handling visibility and styling with CSS classes
- Attaching event listeners to respond to user actions
